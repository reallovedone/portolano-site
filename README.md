# portolano-site

The website of [Portolano](https://github.com/reallovedone/portolano), published at
[portolano.cloud](https://portolano.cloud).

A single static page built with [Astro](https://astro.build), TypeScript and hand-written CSS:
hero, features, shared folders, the vault, a screenshot showcase, security, download and FAQ.
No UI framework, no animation library, no web fonts, no cookies, no analytics and no requests
to third parties from the visitor's browser. Motion is CSS plus a little TypeScript, respects
reduced motion, and the page is complete without JavaScript.

## Development

Requires Node.js 22.23.4 or later (CI uses 24) and pnpm.

```sh
pnpm install
pnpm dev        # http://localhost:4321
pnpm build      # static output in dist/
pnpm check      # type and template checks
pnpm test       # unit tests
```

## How it works

- **Design tokens.** `src/styles/tokens.css` is a verbatim copy of the app's tokens;
  `scripts/sync-tokens.sh` refreshes it from a sibling checkout of the app repository.
  Web-only additions live in `src/styles/web.css`.
- **Copy.** Every visible string is in `src/content/copy.ts`.
- **GitHub data.** Stars, download counts, the latest version and installer links are
  fetched from the GitHub API at build time only (`src/lib/github.ts`). If the API is
  unreachable the build still succeeds and the figures are hidden.
- **Social images.** `public/og.png` and the PNG icons are generated by
  `scripts/og/generate.mjs` (see its header); they are committed, not built.
- **What's new screenshots.** `public/whats-new/<version>/` is read by the app's What's new
  window at fixed URLs. The files are generated from `src/assets/screens/` by
  `node scripts/whats-new.mjs <version> <name>...`, committed, and never changed once
  published.

## Checks

CI runs `pnpm check`, `pnpm test` and `pnpm build` on every pull request.

## Deployment

`.github/workflows/deploy.yml` builds the site and deploys it to GitHub Pages on every push
to `main`, on demand, and every six hours so the figures stay fresh.
